## Observation: packetdiag rejects a first row whose width sum is 0 or at most -2 (final check)
- **Context**: vega FAs packet/R07.02-Range_Error2 (`4-3:`) and R11.01-len_0 (`* A [len = 0]`).
- **Finding**: PacketDiagram.checkFinalError builds the layout (PacketDiagram.java:225-229). adjustColWidth sets colWidth to min(first-row width sum, colWidth) (:387-392); getFullIndicatorInterval returns colWidth below 4 (:260-262), so a sum of 0 divides by zero at :401, and a sum of -2 or less makes `IntStream.limit` negative (IllegalArgumentException); -1 passes. PSystemBuilder turns the throw into an error (:275-281). Width is `len` (last `len=` found by NwDiagram.toSet, unparsable = 1) for `N:`/`*` fields and B-A+1 for `A-B`. With non-negative widths the check fails exactly when every field has width 0.
- **Impact**: modeled in nwdiag-packet-packet.yaml; negative sums are gap fixtures.
- **Confidence**: High (31 jar probes)

## Observation: a whole-block condition can be modeled with one require_pop push plus interpreter-only retry entries
- **Context**: the packet final check depends on all field lines, not one.
- **Finding**: `set` keeps a frame's require_pop slot (engine `_track` ignores `set`), so a state machine cannot leave a pending frame by `set`, and leaving by `pop` returns to the pre-push state. Working pattern: the first field pushes a never-closing context with require_pop (pass 1 validates every line), the end of the block backtracks to that line, and the entries after it decide: a joiner-only `join` (zero field ... first non-zero field, then `set`) accepts, a `reject` refuses, else the generated rule `set`s the post-state. Lines the join swallows were validated in pass 1. Emitters skip the join and reject, so backreferences and conditional groups may live there only.
- **Impact**: reusable for other "final check over all lines" cases when the condition can be decided at its first relevant line by looking ahead.
- **Confidence**: High (soundness of the zero patterns checked against an arithmetic reference in tests/families/test_nwdiag_packet.py)
