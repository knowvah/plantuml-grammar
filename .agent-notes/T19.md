## Observation: bare words fail through CommandCreateElementFull.isForbidden at execute time
- **Context**: T13's open item: gen-description-diagram accepted `licenses`, `emojis`, `foo` and won `license`/`version` blocks before the single-line factories.
- **Finding**: CommandCreateElementFull's regex matches any one-word line (CODE1 `[%pLN_.]+`). `isForbidden` (`descdiagram/command/CommandCreateElementFull.java:134-139`, plain `Pattern` `^[\p{L}0-9_.]+$`) is not checked in `isValid`: `SingleLineCommand2.execute` checks it (`command/SingleLineCommand2.java:164-165`) and returns `CommandExecutionResult.error`, so the factory fails (EXECUTION_ERROR, `PSystemCommandFactory.java:180-187`) and PSystemBuilder moves on to the next factory. Digits are ASCII only: `x١` is accepted. The description model narrows CCEF with a lookahead and puts a `reject` right after it. Default dispatch now sends `license`/`version`/`authors`/`stdlib` to the embedded single-line models and rejects `licenses`/`emojis`/`arkban`/`help`, matching the jar on all 8.
- **Impact**: `tests/layers/test_document.py` restricts `start_map` for the single-line group only because of this; the restriction can probably be lifted (not my file).
- **Confidence**: High (oracle-verified)

## Observation: the orphan state (`}` popping the root) differs between description and class
- **Context**: modelling the group stack for DescriptionDiagramFactory.
- **Finding**: after a root-closing `}`, description still accepts hide/show/remove/restore of entities, `url of`, legends and `hide @unlinked`; class rejects entity hide/show. Elements, links, openers, `together`, `}`, notes, archimate, domain, map and JSON fail. `newpage` creates a fresh diagram with a new stack (`descdiagram/command/CommandNewpage.java:77-85`), so a `}` after it pops the new root and ports are root-level again.
- **Impact**: do not reuse class-groups' CG_ORPHAN_UNSAFE for other factories; probe each factory's list.
- **Confidence**: High (52 jar probes)

## Observation: `archimate X` with one space never matches CommandArchimate
- **Context**: archimate fixtures.
- **Finding**: CommandArchimate is `archimate` + spaceOneOrMore + optional COLOR + spaceOneOrMore (`descdiagram/command/CommandArchimate.java:71-74`); with an empty color the two space runs need two spaces, so `archimate A` is a syntax error while `archimate #red A` and `archimate  A` work.
- **Confidence**: High (oracle-verified)
